# Release 6.3.0 — 2026-11-05

## Summary

ycc 6.3.0 makes `install.sh` native-only. `install` and `sync` now install Claude, Codex and Cursor through their plugin CLIs (`ycc-mcp@ycc` and `ycc-hooks@ycc` included), and they clean up files left by older installs, but only files ycc can prove it wrote. The legacy file-copy and config-merge routes and the `migrate` subcommand are gone.

## Added

977fbb65 feat(install)!: install natively only; drop legacy install routes (YAN-1962) (#534)

- Claude: `--intent mcp` installs `ycc-mcp@ycc` and `--intent hooks` installs `ycc-hooks@ycc`, at project scope by default and user scope with `--global`. This fixes `refusing to replace directory with symlink: ~/.claude/hooks`.
- Codex: `base` installs `ycc@ycc` and `ycc-mcp@ycc` with `codex plugin add`, and `--intent mcp` installs `ycc-mcp@ycc`.
- Cursor: `install` registers the GitHub marketplace with `agent plugin marketplace add` and lists which packages to select in `/plugins`.
- OMP: old `omp plugin link` and marketplace installs are cleaned up during `install`.

## Changed

- The legacy cleanup (formerly `migrate --apply`) runs as part of install, sync and `remove --intent base`. It removes only files identical to what ycc wrote, links ycc owns, and config entries ycc recorded. Edited copies and your own files are kept and reported. If the cleanup fails, it prints a warning and the install continues.

## Removed

977fbb65 feat(install)!: install natively only; drop legacy install routes (YAN-1962) (#534)

- The `migrate` subcommand (`--apply`, `--marketplace-source`) and the deprecation hints.
- Claude: the `~/.claude/hooks` symlink, the settings `hooks` merge, the MCP merge into `~/.claude.json` / `.mcp.json`, and standalone skill, agent and command copies.
- Codex: the `local-ycc-plugins` catalog, plugin symlinks, cache copies for Codex builds older than 0.160, the `[mcp_servers]` merge and standalone skill copies.
- Cursor: every file copy (skills, agents, commands, rules bundle, the hooks carrier, the MCP merge).
- `--skills`, `--agents`, `--commands`, `--mcps`, `--with-deps`, `--skills-home` and `--hooks <events>` for claude, codex, cursor and omp. They still apply to opencode and agents.

## Fixed

- `remove --target cursor --intent <content>` no longer drops the whole ycc marketplace; only `--intent base` does.

## Upgrade Notes

**Breaking for installer users.** Run your usual `install`/`sync` command again. It installs the native packages and removes legacy copies that ycc can prove it wrote.

- `ycc migrate` now exits with a notice. Use `install`/`sync` instead.
- Claude hooks and MCP: `ycc sync --target claude --intent hooks,mcp --global` for user scope, or drop `--global` for the current project. Claude hooks need Claude Code 2.1.300 or later.
- Codex now needs the Codex CLI 0.160 or later (`codex plugin`). Custom agents in `~/.codex/agents`, settings and rules still come from the installer.
- Cursor has no non-interactive plugin install. After `ycc install --target cursor`, select the packages it names in `/plugins` (agent CLI or IDE).
- Scripts that pass `--skills`, `--agents`, `--commands`, `--mcps` or `--hooks <events>` for claude, codex or cursor must drop those flags. With `--target all` the flags still apply to opencode and agents and are skipped elsewhere with a notice.
