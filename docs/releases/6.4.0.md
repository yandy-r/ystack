# Release 6.4.0 — 2026-11-09

## Summary

ycc 6.4.0 adds the `mcp-parity` skill for planning and syncing a Linear project with one issue per API/app capability, maps the Haiku model tier to `@task` for OMP, and pins the OMP `unpin` built-in so the OMP built-in command check passes.

## Added

- `mcp-parity` skill (`/ycc:mcp-parity`) researches a repo's API or app surface and creates or syncs a Linear project, milestones, and prioritized issues for one-to-one MCP parity. Re-runs apply only the delta (added, changed, removed, revived) via a manifest Document, with deterministic diffing in `capability_diff.py`, OpenAPI 3.x inventories via `openapi_inventory.py`, and surface hints from `detect-api-surface.sh` (#540, closes #539).
- OMP model policy: `haiku` maps to `@task`, and `code-finder` now runs on `haiku`.

## Changed

- `code-finder` agent model: `sonnet` → `haiku`.

## Removed

- None this release.

## Fixed

- OMP built-in command pin: `unpin` is now in the reserved-name set in `scripts/generate_omp_commands.py`, so `scripts/omp_builtin_commands.py` passes against the live `omp` (18.18.1).
