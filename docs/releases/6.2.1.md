# Release 6.2.1 — 2026-11-04

## Summary

ycc 6.2.1 removes the `linear-personal` MCP server from `ycc-mcp` on every runtime; `linear` is now the only Linear server. It also fixes saved `external_directory` approvals in the opencode npm package and a CRLF `.gitignore` check in branch prep, and registers the deferred Pi target in the package model.

## Upgrade Notes

Removing a server from the source does not delete it from configs that an earlier `install.sh` merged. To drop `linear-personal`, run `./install.sh remove --target <claude|cursor|codex|opencode> --intent mcp --mcps linear-personal --global` from a v6.2.0 checkout, or delete the entry by hand. Native `ycc-mcp` plugins pick up the change on update. If you edited the entry yourself, add `--force`.

Publishing the `v6.2.1` tag ships the experimental, opt-in `@yandy-r/ycc-opencode` package. The `install.sh` file copy remains the primary opencode path.
