# Release 6.2.0 — 2026-11-04

## Summary

ycc 6.2.0 adds the artifact store: planning, implementation, review and report skills can keep their artifacts as Linear documents and issues (with a local `.ycc/artifacts/` cache) instead of `docs/plans` and `docs/prps` files, and `ycc:init` records the choice in a committed pointer. Linear is now the default store for repositories without a store configuration; existing local plans and reviews keep working. `install.sh` gains `--dry-run` on every target and step, and project scope for the settings step and Claude hooks.

## Upgrade Notes

No breaking changes; no action is required to keep existing installs working.

- Artifact store default: in a repository with no store configuration, planning and review skills now write to Linear (default `store: linear`). Existing local plans and reviews under `docs/plans/` and `docs/prps/reviews/` are still found and used in local mode, with a one-line pin hint. To keep everything local, add `store: local` to `.plans-config`, or pass `--store=local` to a single run. Linear mode needs a reachable Linear MCP server.
- `install.sh --dry-run` now works for every target's `sync` and `remove`; `--target all --only <step>` skips targets without that step instead of failing.
- Project-scope installs (`--project`) now cover the settings step and Claude hooks through the native `ycc-hooks` plugin.
